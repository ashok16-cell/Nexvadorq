# NEXVADORAQ Android App

Android WebView app for the NEXVADORAQ startup platform.

- Package: `con.nexvadoraq.app`
- Website: https://ashok16-cell.github.io/Nexvador/
- Minimum Android: 6.0 (API 23)

## Build APK
1. Open the **Actions** tab in this repository.
2. Select **Build NEXVADORAQ APK**.
3. Click **Run workflow** (or wait for the build after a push).
4. Open the completed workflow run and download the `NEXVADORAQ-debug-apk` artifact.

Firebase phone OTP is not connected yet. Add the Firebase Android configuration file (`app/google-services.json`) and enable Phone sign-in in Firebase before adding OTP authentication.
